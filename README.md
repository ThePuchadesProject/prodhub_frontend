## English

Frontend application for **ProdHub**, a full-stack product management app built with the PERN stack (PostgreSQL, Express, React, and Node.js).

### What the project does

This repository contains the client-side web application used to manage a product catalog. The goal of this frontend is to provide a clean and responsive interface to view, create, edit, update availability, and delete products by connecting to the ProdHub REST API.

### Tech Stack

* **Library & Language:** React 19, TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS v4
* **Routing:** React Router
* **HTTP & Validation:** Axios, Zod *(planned)*

### Roadmap

- [x] Initial project setup with React, TypeScript, Vite, and Tailwind CSS
- [x] Routing and main application layout
- [ ] Connect to the ProdHub REST API and validate data
- [ ] Product list view and product creation form
- [ ] Edit products and update availability
- [ ] Delete products from the catalog

### Local Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/ThePuchadesProject/prodhub_frontend.git
   cd prodhub_frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   The app will run locally at `http://localhost:5173`.

## Español

Aplicación frontend para **ProdHub**, una aplicación full-stack de administración de productos construida con el stack PERN (PostgreSQL, Express, React y Node.js).

### Qué hace el proyecto

Este repositorio contiene la aplicación web del lado del cliente para gestionar un catálogo de productos. El objetivo de este frontend es ofrecer una interfaz limpia y práctica para ver, crear, editar, actualizar la disponibilidad y eliminar productos conectándose a la REST API de ProdHub.

### Tech Stack

* **Librería y Lenguaje:** React 19, TypeScript
* **Herramienta de compilación:** Vite
* **Estilos:** Tailwind CSS v4
* **Enrutamiento:** React Router
* **HTTP y Validación:** Axios, Zod *(planificado)*

### Roadmap

- [x] Configuración inicial del proyecto con React, TypeScript, Vite y Tailwind CSS
- [x] Enrutamiento y layout principal de la aplicación
- [ ] Conexión con la REST API de ProdHub y validación de datos
- [ ] Listado de productos y formulario de creación
- [ ] Edición de productos y cambio de disponibilidad
- [ ] Eliminación de productos del catálogo

### Instalación local

1. Clona este repositorio:
   ```bash
   git clone https://github.com/ThePuchadesProject/prodhub_frontend.git
   cd prodhub_frontend
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
   La aplicación estará disponible localmente en `http://localhost:5173`.
